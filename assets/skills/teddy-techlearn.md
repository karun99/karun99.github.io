# Teddy TechLearn

An AI study companion for M.Tech CSE with a graph of what each learner knows.

Teddy TechLearn is an MCP (Model Context Protocol) server by Sai Karun Nandipati. It is built by the author, not yet published to a registry.

## What it does

- Tracks a learner graph of topics a student has mastered vs. needs review.
- Indexes course material (PDF, DOCX, XLSX, HTML) for retrieval.
- Answers and quizzes from the indexed material.

## Tools it exposes

- **study companion** — Ask questions and get answers grounded in the indexed course material.

## How to use it

**Availability**
An OpenCode-compatible plugin and study companion. Deployed at techlearn-xi.vercel.app.
