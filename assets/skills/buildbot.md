# BuildBot

A student coding assistant: walks a research paper to SRS to working code.

BuildBot is an MCP (Model Context Protocol) server by Sai Karun Nandipati. It is built by the author, not yet published to a registry.

## What it does

- Takes a research paper through SRS, a checklist, and implementation to working code.
- Companion to Collabuild, focused on the student/coding path.

## Tools it exposes

- **(assistant)** — Guide a paper from spec to implemented code.

**Availability**
