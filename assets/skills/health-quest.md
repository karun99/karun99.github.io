# Health Quest

An ethics-first food education game that scores healthy choices.

Health Quest is an MCP (Model Context Protocol) server by Sai Karun Nandipati. It is built by the author, not yet published to a registry.

## What it does

- Teaches healthy-eating habits through a game loop with health scoring.
- Ethics-first: educational guidance, not clinical advice.

## Tools it exposes

- **companion** — Guide food/health education scenarios and score outcomes.

## How to use it

**Availability**
Deployed at health-quest-wheat.vercel.app. Educational only — not medical advice.
