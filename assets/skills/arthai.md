# ArthAI

An agentic commerce gateway for MSMEs with six-layer financial governance.

ArthAI is an MCP (Model Context Protocol) server by Sai Karun Nandipati. It is built by the author, not yet published to a registry.

## What it does

- Runs agentic commerce for small businesses under six layers of financial governance.
- Built for the Razorpay Buildathon.

## Tools it exposes

- **(gateway)** — Orchestrate commerce/finance agents under governance.
